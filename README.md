# Michica Provato — Portfolio

Static portfolio site for Michica Provato, design leader (Toronto).

Four pages — [Home](index.html), [Work](work.html), [About](about.html), [Contact](contact.html) — built as plain HTML/CSS from the Claude Design project, with responsive WebP images (srcset + lazy loading). No build step; deployable directly to GitHub Pages.

## Local preview

```bash
npx serve .
```

## Images

All images live in `assets/` as WebP at two responsive sizes each (~750 KB for the entire set). Source images came from the design project, the original case-study PDFs, and the portfolio review deck.
